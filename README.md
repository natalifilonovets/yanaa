# English vocabulary practice

Интерактивное задание для взрослых: 24 ситуации с выбором одного из двух слов или выражений, объяснения и переводы на украинском, результаты и повтор ошибок.

Откройте `index.html` в браузере. Установка и сборка не нужны.

Клавиши `1` и `2` выбирают ответ. Интерфейс адаптирован для телефона и компьютера.
